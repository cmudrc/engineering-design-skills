# Skill catalog

The library has one overall process skill and 26 method ideas. Four skills have draft implementations; the remaining 23 are planned. A draft status does not imply behavioral validation.

## Draft implementations

| Skill | Purpose |
|---|---|
| [Engineering design process](../skills/engineering-design-process/SKILL.md) | Guide method selection and iterative design decisions. |
| [Technical benchmarking](../skills/technical-benchmarking/SKILL.md) | Compare existing solutions using traceable, comparable evidence. |
| [Morphological synthesis](../skills/morphological-synthesis/SKILL.md) | Combine functional solution principles into coherent concepts. |
| [Design optimization formulation](../skills/design-optimization-formulation/SKILL.md) | Translate a design decision into a mathematical optimization problem. |
