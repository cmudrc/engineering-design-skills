# Worked example: a cooler project worth pursuing

All project statements below are synthetic teaching inputs. There is no completed market study or approved production budget.

## Rough request

“We might build a better cooler for our outdoor-event crew. The ones we use are awkward. Could this be a project?”

A follow-up establishes that staff repeatedly move drinks between tables, the organizer buys the equipment, and the team has access to a basic workshop. The crew has not yet agreed on a thermal protocol or acceptable mass. No demand outside this organization has been demonstrated.

## Planning interpretation

The opportunity is easier handling during service. A thicker insulated box is a possible solution, not the mission. The initial product scope is the crew's mobile drink-service task; replacing the organizer's bulk refrigeration is outside that scope.

| Mission element | Proposed statement | Status |
|---|---|---|
| Product description | A portable way for event staff to carry and serve chilled drinks between tables | Proposed |
| Benefit | Reduce awkward carrying while preserving useful cooling performance | Proposed; needs observation |
| Organizational goal | Improve the crew's service workflow | Supplied aim; magnitude of benefit unknown |
| Primary users | Event staff carrying and serving drinks | Supplied |
| Buyer | Event organizer | Supplied |
| Other stakeholders | People loading, cleaning, storing, and maintaining the equipment | To confirm |
| Development context | Basic workshop access | Supplied; actual capabilities need checking |
| Open choices | Container architecture, carrying arrangement, insulation, coolant, and refill strategy | Intentionally open |

## Next effort

Propose a bounded Phase 1 effort: observe a typical service cycle, collect needs from staff and the buyer, compare existing equipment, and develop contrasting concepts. Establish payload and thermal requirements from use evidence before treating any weight or duration target as mandatory.

Budget and calendar dates remain open. Workshop access does not prove that a production process is available. A mission can be useful before those details are complete, but the team should resolve resource commitments before promising a delivery date.

## Handoff

Recommendation: proceed with a small learning effort if the project owner supports it. The planning record does not claim that the project has been approved, that a market exists beyond the crew, or that a particular cooler design has been selected.
